# PowerMeter Firmware

Firmware for an ESP32 based powermeter. Users can interact with this device using the [app](https://github.com/theChroma/powermeter_app).

### Features
- Tracks power consumption over different, configurable periods of time
- Delivers live measurements for voltage, current, active-, reactive-, apparent power and the power factor
- REST API to fetch measurements, and configureing the device
- No internet connection required

### Building and Flashing
This project can be built and flashed using [PlatformIO](https://platformio.org/)
